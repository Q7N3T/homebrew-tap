# Q7N3T Homebrew tap

```sh
brew trust --cask q7n3t/tap/wirrow
brew install --cask q7n3t/tap/wirrow
```

[Wirrow](https://q7n3t.github.io/wirrow/) — drag and drop files between a Mac and an Android phone or Nintendo Switch, over a cable.

The cask is updated automatically with every Wirrow release. Wirrow also updates itself.
